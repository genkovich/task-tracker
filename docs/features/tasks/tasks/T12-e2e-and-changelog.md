# T12 — E2E + CHANGELOG

## Why

[test-plan.md](../test-plan.md): e2e — єдиний рівень, що покриває звʼязку «редактор змінив →
глядач побачив» через справжній UI, а не через окремі шари.

## What

Один спек, один сценарій (набір ділить бюджет 60 запитів/хв на IP, тож зайвих проходів по
дошці не робимо):

1. створити задачу quick-add-ом
2. відкрити деталі, вписати опис, обрати пріоритет, задати дедлайн, зберегти
3. додати коментар
4. побачити маркери на картці
5. видати публічний лінк, відкрити його, клікнути картку — ті самі деталі read-only

Плюс секція в `CHANGELOG.md` у partner-facing стилі попередніх записів.

## Definition of Done

- [ ] спек зелений на живому локальному стеку (`workers=1`)
- [ ] сценарій перевіряє саме маркери на картці, а не лише вміст модалки
- [ ] глядацька частина перевіряє відсутність полів вводу
- [ ] CHANGELOG-секція називає нові роути, міграції й артефакти паперу
